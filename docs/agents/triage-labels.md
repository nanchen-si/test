# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual Chinese label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage`             | `需要分诊`             | 维护者需要评估此 issue |
| `needs-info`               | `需要信息`             | 等待报告者补充信息 |
| `ready-for-agent`          | `可交给代理`           | 信息完整，可交给代理处理 |
| `ready-for-human`          | `可交给人工`           | 需要人工实施 |
| `wontfix`                  | `不处理`               | 不会处理此 issue |

When a skill mentions a canonical role, use the corresponding Chinese label from this table.
