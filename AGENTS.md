## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage roles use Chinese labels: `需要分诊`, `需要信息`, `可交给代理`, `可交给人工`, `不处理`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with root-level `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

## 提交规则

每次对仓库文件进行改动后，都必须执行一次 `git commit`，并在提交信息中明确说明本次改动事项。
